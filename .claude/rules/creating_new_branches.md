
When creating a new branch, always prefix the path with the issue id if available. The path should be in the format of `type/id/name_of_branch` or at least `type/id`.

Example: `feat/EX-12/new_feature` or `perf/EX-12`

The type should be one of the following:
- `feat` - for new features
- `fix` - for bug fixes
- `docs` - for documentation changes
- `refactor` - for code refactoring
- `style` - for code style changes
- `chore` - for chore tasks
- `test` - for test changes
- `perf` - for performance changes
- `ci` - for CI/CD changes
- `tool` - for tool changes
